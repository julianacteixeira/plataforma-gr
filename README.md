\# Plataforma de Guest Relations



Sistema interno para a rotina de Guest Relations de um hotel/resort, com foco

em registrar de forma confiável e auditável as decisões de "vipagem"

(planejamento de experiências para hóspedes VIP).



\## Documentação

\- Visão do produto: `docs/product/vision.md`

\- Backlog: `docs/product/backlog.md`

\- Log de decisões: `docs/decisions/decision-log.md`

\- Estado atual do projeto: `docs/handoff/current-state.md`

\- Próximos passos: `docs/handoff/next-steps.md`



\## Stack

Python, Flask, HTML/CSS/JS, SQLAlchemy, Flask-Migrate, Flask-Login, openpyxl.

Em desenvolvimento inicial. Nenhuma versão está em produção.
